## npm модуль для создания полноценного банка на express, sequelize (sqlite).

## О проекте

**sequelize-game-bank** — это готовый бэкенд-модуль, который за пару строк кода разворачивает изолированную банковскую систему для вашей игры или тестовой среды. Он автоматически создает базу данных SQLite через Sequelize и монтирует защищенные REST API роуты для Express.

* **Изолированная песочница:** Идеально для безопасной симуляции балансов, переводов и транзакций без риска реальных денег.
* **Всё включено:** База данных (SQLite), модели (Sequelize) и готовые эндпоинты (Express) поставляются в одном пакете.
* **Быстрый старт:** Не требует настройки внешних баз данных — всё работает "из коробки" в локальном файле или памяти.
* **Поддержка Nodemailer** Возможность отправлять сообщения на gmail

## 🚀 Установка

Установите пакет через ваш любимый менеджер пакетов:

```bash
npm install sequelize-game-bank
```

## 💻 Быстрый старт

Просто подключите модуль в ваше существующее Express-приложение:

```javascript

const app = (async function initBank(){
    try {
        return await BANK();
    } catch {
        console.log("Ошибка при инициализации банка!");
    }
})();
```
